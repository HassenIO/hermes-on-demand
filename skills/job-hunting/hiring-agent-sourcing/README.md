# hiring-agent-sourcing

Turn job listings into hiring-agent rows in Notion.

Invoke in chat with `/hiring-agent-sourcing`, or ask Hermes to load this skill. Behavior lives in `SKILL.md` and the files next to it. Those files are not in Git.

After editing here, run `make skills-push`. If the skill was changed on the VPS, run `make skills-pull` first so you do not overwrite that copy.

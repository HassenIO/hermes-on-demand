# hiring-agents-scraper

Find freelancermap hiring agents and save them to Notion.

Invoke in chat with `/hiring-agents-scraper`, or ask Hermes to load this skill. Behavior lives in `SKILL.md` and the files next to it. Those files are not in Git.

After editing here, run `make skills-push`. If the skill was changed on the VPS, run `make skills-pull` first so you do not overwrite that copy.
